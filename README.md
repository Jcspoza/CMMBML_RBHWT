# Taller Programación y Robótica en CMM Benito Martin Lozano - Robotica - Programas de test HW básicos.

Repositorio de programas básicos de test de montajes de robotica para probar elementos Hardware, escritos en micropython y testados con el micro Controlador Raspberry Pico en todas sus variantes: Pico, Pico 2, Pico W , Pico 2W

Si el programa usa la conexión wifi o bluetooth solo se podrán usar las variantes 'W', y se indicará en notas.

Si algun programa no funciona en absoluto o funcioona con mucha lentitud en las variantes '1' , se  indicara en notas.
